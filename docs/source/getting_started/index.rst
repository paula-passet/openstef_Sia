Getting Started
===============

Everything you need to go from a fresh install to running your first energy forecasts with OpenSTEF, a modular Python library for short-term load forecasting. Pick your starting point below based on your experience level.

- **Installation** (:doc:`installation`)
   Install the OpenSTEF library on your system, including system requirements and optional dependencies — start here if you are new to OpenSTEF.

- **Quickstart** (:doc:`quickstart`)
   The fastest path to a working forecast: a minimal end-to-end example using sample data that you can run in minutes.

- **Your First Forecast** (:doc:`first_forecast`)
   A step-by-step tutorial walking through data preparation, model training, and generating predictions — ideal if you want to understand the full workflow before adapting it to your own data.

- **Backtesting Models** (:doc:`backtesting`)
   Learn how to evaluate and compare model performance using historical data before deploying a model to production.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend the library with custom data sources, feature engineering, and model configurations — aimed at experienced users who need to tailor OpenSTEF to specific use cases.
