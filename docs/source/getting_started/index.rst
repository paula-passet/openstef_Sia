Getting Started
===============

This section guides you through your first steps with OpenSTEF, from installation to building production-ready forecasting pipelines. Whether you're new to energy forecasting or integrating OpenSTEF into an existing system, you'll find the right starting point here.

If you're completely new to OpenSTEF, start with :doc:`installation` to set up the library on your system. This covers system requirements, package options, and troubleshooting common installation issues.

Once installed, :doc:`quickstart` provides the fastest path to your first forecast with a minimal working example. This single-page guide gets you from zero to a working forecast in minutes using sample data.

For a more thorough introduction, :doc:`first_forecast` walks through a complete forecasting workflow step-by-step. You'll learn how to prepare your data, configure a model, train it, and generate predictions with detailed explanations of each stage.

After mastering basic forecasting, :doc:`backtesting` shows how to evaluate and compare different models using historical data. This tutorial demonstrates OpenSTEF's backtesting framework for rigorous model validation before deployment.

Finally, :doc:`advanced_customization` is for power users who need to extend the library. Learn how to create custom data transformations, implement your own forecasting models, and integrate external components into OpenSTEF's workflow system.
