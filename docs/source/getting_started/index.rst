Getting Started
===============

This section takes you from installing the OpenSTEF library through running your first forecasts, with tutorials suited to both newcomers and experienced users looking to go deeper.

- **Installation** (:doc:`installation`)
   Install the OpenSTEF library on your system — start here if you haven't set it up yet.

- **Quickstart** (:doc:`quickstart`)
   Run your first forecast in minutes using sample data, with minimal setup required.

- **Your First Forecast** (:doc:`first_forecast`)
   Step-by-step tutorial covering data preparation, model training, and generating predictions with full explanations.

- **Backtesting Models** (:doc:`backtesting`)
   Learn how to evaluate and compare models against historical data to validate forecast quality.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend the library with custom data sources, features, and models — for users ready to go beyond the defaults.

.. note::

   New to OpenSTEF? Start with :doc:`installation`, then follow the :doc:`quickstart` to see results fast.
   If you want a deeper understanding of the full workflow, :doc:`first_forecast` walks through every step with explanations.
