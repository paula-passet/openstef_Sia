Getting Started
===============

This section helps you start using OpenSTEF, a Python library for short-term energy forecasting. Whether you're new to energy forecasting or looking to integrate OpenSTEF into your workflow, you'll find the resources you need here.

What You'll Learn
-----------------

You'll learn how to install the library, create your first forecast, evaluate model performance using backtesting, and customize OpenSTEF's components to fit your specific needs. By the end of this section, you'll understand the core workflow and be ready to build production forecasting systems.

Finding Your Starting Point
---------------------------

Begin with the **installation** guide to set up OpenSTEF on your system. The library uses a modular architecture, so you can install only what you need—from lightweight core models to the complete toolkit with evaluation and analysis tools.

Once installed, the **quickstart** provides the fastest path to your first forecast. This single-page guide shows a minimal working example using sample data, perfect for verifying your installation and understanding the basic API.

For a deeper understanding, work through **first forecast**, which walks you step-by-step through data preparation, model configuration, training, and prediction. This tutorial explains the reasoning behind each step and introduces key concepts like feature engineering and model pipelines.

The **backtesting** tutorial demonstrates how to evaluate and compare different forecasting models using historical data. You'll learn to set up proper train-test splits, run backtests, and interpret performance metrics—essential skills for building reliable forecasting systems.

Finally, **advanced customization** shows power users how to extend the library with custom data sources, preprocessing steps, and model components. This tutorial reveals OpenSTEF's flexibility for specialized forecasting scenarios.
