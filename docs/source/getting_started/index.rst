Getting Started
===============

This section takes you from installing OpenSTEF to running your first forecasts, with tutorials suited to both new users and those looking to extend the library.

- **Installation** (:doc:`installation`)
   Install the OpenSTEF library and its dependencies — start here if you haven't set up OpenSTEF yet.

- **Quickstart** (:doc:`quickstart`)
   Run a working forecast in minutes using sample data, with minimal setup required.

- **Your First Forecast** (:doc:`first_forecast`)
   Step-by-step tutorial covering data preparation, model training, and generating predictions with full explanations.

- **Backtesting Models** (:doc:`backtesting`)
   Learn how to evaluate and compare forecast models against historical data to validate performance.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend OpenSTEF with custom data sources, features, and models for production or research use cases.

.. note::

   New to OpenSTEF? Start with :doc:`installation`, then follow :doc:`quickstart` for an immediate hands-on introduction.
   If you prefer a deeper walkthrough, :doc:`first_forecast` covers the same ground with more explanation.
