Getting Started
===============

This section takes you from installing OpenSTEF to running fully customized forecasting pipelines, with guides suited to every experience level.

- **Installation** (:doc:`installation`)
   Set up the OpenSTEF library on your system — start here if you haven't installed it yet.

- **Quickstart** (:doc:`quickstart`)
   Run your first forecast in minutes using sample data, with minimal setup required.

- **Your First Forecast** (:doc:`first_forecast`)
   Step-by-step tutorial walking through data preparation, model training, and generating predictions with full explanations.

- **Backtesting Models** (:doc:`backtesting`)
   Learn how to evaluate and compare models against historical data to validate forecast quality.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend the library with custom data sources, feature engineering, and model configurations for production use cases.

.. note::

   New to OpenSTEF? Start with :doc:`installation`, then follow the :doc:`quickstart` to see a working forecast before diving deeper.
