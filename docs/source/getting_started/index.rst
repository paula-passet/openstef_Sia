Getting Started
===============

Welcome to OpenSTEF! This section will help you get up and running with OpenSTEF, an open-source Python library for short-term energy forecasting.

.. important::
   OpenSTEF is a **Python library**, not a deployable application. It provides the building blocks for creating your own energy forecasting applications. You'll need to write code to use it effectively.

What You'll Learn
-----------------

This getting started guide covers everything you need to begin forecasting with OpenSTEF:

* **Quick Start**: Get from installation to your first forecast in under 10 minutes
* **Step-by-step tutorials**: Deep dive into each component of the forecasting workflow
* **Backtesting**: Evaluate model performance on historical data
* **Advanced topics**: Customize OpenSTEF for your specific needs

Prerequisites
-------------

Before you begin, you should have:

* Basic Python programming knowledge
* Familiarity with pandas DataFrames
* Understanding of time series data concepts
* Python 3.8 or higher installed

Installation
------------

Install OpenSTEF using pip:

.. code-block:: bash

   pip install openstef

For development or advanced features, see the :doc:`../contribute/development_setup` guide.
