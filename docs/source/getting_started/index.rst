Getting Started
===============

OpenSTEF is a Python library for creating short-term energy forecasts using machine learning. This section guides you through installation, your first forecast, and advanced customization options.

Whether you're exploring the library for the first time or ready to build production forecasts, these pages will help you get up and running quickly.

What You'll Learn
-----------------

This section covers everything needed to start forecasting with OpenSTEF:

- Installing the library and its dependencies
- Creating your first forecast with minimal code
- Understanding the complete forecasting workflow
- Evaluating model performance with backtesting
- Customizing models and pipelines for specific needs

Where to Start
--------------

**New to OpenSTEF?** Start with :doc:`installation` to set up your environment, then move to :doc:`quickstart` for a minimal working example that produces a forecast in minutes.

**Ready to learn the details?** The :doc:`first_forecast` tutorial walks through data preparation, model training, and prediction generation step-by-step with full explanations.

**Evaluating model quality?** Learn how to compare different models and validate performance using historical data in :doc:`backtesting`.

**Need advanced features?** The :doc:`advanced_customization` guide shows how to extend OpenSTEF with custom data sources, feature engineering, and model configurations.
