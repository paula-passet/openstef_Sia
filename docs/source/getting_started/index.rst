Getting Started
===============

This section takes you from installing OpenSTEF to running production-ready forecasts, with guides suited to both newcomers and experienced users.

- **Installation** (:doc:`installation`)
   Install the library and its packages on your system — start here if you are setting up OpenSTEF for the first time.

- **Quickstart** (:doc:`quickstart`)
   Get a working forecast running in minutes using the preset workflow with minimal configuration.

- **Your First Forecast** (:doc:`first_forecast`)
   Step-by-step tutorial that walks through the full forecasting workflow using the custom pipeline, with explanations at each stage.

- **Backtesting Models** (:doc:`backtesting`)
   Learn how to evaluate a trained model against historical data using the BEAM backtesting pipeline.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend OpenSTEF with custom data sources, feature engineering, and model configurations for power users.
