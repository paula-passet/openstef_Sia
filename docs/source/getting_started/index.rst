Getting Started

Everything you need to go from a fresh environment to running your first OpenSTEF forecast — install the library, then follow the quickstart to see it in action.

**Installation** (:doc:`installation`)
   Install OpenSTEF on your system, including system requirements and optional dependencies — start here if you haven't set up the library yet.

**Quickstart** (:doc:`quickstart`)
   Run your first forecast in minutes using a minimal working example with a preset pipeline workflow — the fastest path to a working result.
