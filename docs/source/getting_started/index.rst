Getting Started
===============

Everything you need to go from a fresh environment to running your first energy forecast with OpenSTEF.

**Installation** (:doc:`installation`)
   Install the library, check system requirements, and set up optional dependencies — start here if you are new to OpenSTEF.

**Quickstart** (:doc:`quickstart`)
   Run a working forecast in minutes using a preset workflow and sample data, with no prior OpenSTEF knowledge required.
