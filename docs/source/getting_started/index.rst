Getting Started
===============

Everything you need to go from a fresh install to running your first energy forecasts with OpenSTEF, organised by experience level.

- **Installation** (:doc:`installation`)
   Install the OpenSTEF library and its dependencies — start here if you haven't set up OpenSTEF yet.

- **Quickstart** (:doc:`quickstart`)
   Run a complete forecast in minutes using the built-in preset workflows, with minimal configuration required.

- **Your First Forecast** (:doc:`first_forecast`)
   Step-by-step tutorial that walks through building a forecast pipeline from scratch, with explanations of each stage.

- **Backtesting Models** (:doc:`backtesting`)
   Evaluate model performance on historical data to understand accuracy before deploying to production.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend OpenSTEF with custom data sources, feature engineering, and model components for power users.
