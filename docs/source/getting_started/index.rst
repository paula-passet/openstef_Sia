Getting Started
===============

This section takes you from installing OpenSTEF through running your first forecasts, with tutorials suited to both newcomers and experienced users looking to go deeper.

- **Installation** (:doc:`installation`)
   Install the library on your system — start here if you haven't set up OpenSTEF yet.

- **Quickstart** (:doc:`quickstart`)
   Run your first forecast in minutes using sample data, with minimal setup required.

- **Your First Forecast** (:doc:`first_forecast`)
   Step-by-step tutorial covering data preparation, model training, and generating predictions — the right starting point if you want to understand how the pieces fit together.

- **Backtesting Models** (:doc:`backtesting`)
   Evaluate and compare model performance using historical data to build confidence before deploying forecasts.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend OpenSTEF with custom data sources, feature engineering, and model configurations — aimed at experienced users who need to tailor the library to specific use cases.

.. note::
   New to OpenSTEF? Follow the pages in order: **Installation → Quickstart → Your First Forecast**.
   Already familiar with the basics? Jump straight to **Backtesting** or **Advanced Customization**.
