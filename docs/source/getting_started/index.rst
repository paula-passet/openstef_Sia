Getting Started
===============

This section helps you start using OpenSTEF, a Python library for short-term energy forecasting. Whether you're creating your first forecast or customizing advanced features, these guides will get you up and running quickly.

What You'll Learn
-----------------

You'll learn how to install OpenSTEF, create forecasts with minimal code, understand the forecasting workflow, evaluate model performance through backtesting, and customize the library for specific use cases.

Where to Start
--------------

**New to OpenSTEF?** Start with :doc:`installation` to set up the library, then move to :doc:`quickstart` for a minimal working example that produces a forecast in minutes.

**Ready to learn the details?** The :doc:`first_forecast` tutorial walks through each step of the forecasting workflow with explanations of data preparation, model training, and prediction generation.

**Want to evaluate models?** The :doc:`backtesting` guide shows how to compare different models and configurations using historical data to measure forecast accuracy.

**Need advanced control?** The :doc:`advanced_customization` tutorial covers custom data sources, feature engineering, model selection, and evaluation metrics for power users.
