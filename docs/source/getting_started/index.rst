Getting Started
===============

Everything you need to go from a fresh environment to running your first short-term energy forecast with OpenSTEF.

**Installation** (:doc:`installation`)
   Install the library, check system requirements, and choose which packages you need — start here if you haven't set up OpenSTEF yet.

**Quickstart** (:doc:`quickstart`)
   Run a complete forecast in minutes using a preset workflow and built-in sample data — the fastest path to seeing OpenSTEF in action.
