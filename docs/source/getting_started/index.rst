Getting Started
===============

This section takes you from installing the OpenSTEF library through running your first forecasts, with separate guides for beginners and experienced users who want to go deeper.

- **Installation** (:doc:`installation`)
   Install the OpenSTEF library on your system — start here if you haven't set it up yet.

- **Quickstart** (:doc:`quickstart`)
   Run your first forecast in minutes using sample data, with minimal setup required.

- **Your First Forecast** (:doc:`first_forecast`)
   A step-by-step tutorial covering data preparation, model training, and generating predictions — the right starting point if you want to understand the full workflow.

- **Backtesting Models** (:doc:`backtesting`)
   Learn how to evaluate and compare model performance against historical data before deploying to production.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend OpenSTEF with custom data sources, feature engineering, and model configurations — aimed at users already comfortable with the basics.

.. note::

   New to OpenSTEF? Start with :doc:`installation`, then follow the :doc:`quickstart` to see the library in action before diving into the full tutorial.
