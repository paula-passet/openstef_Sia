Getting Started
===============

OpenSTEF is an open-source Python library for short-term energy load forecasting, providing complete pipelines for data preprocessing, feature engineering, model training, and probabilistic prediction. This section takes you from installation through your first working forecasts.

- **Installation** (:doc:`installation`)
   Install the library and its dependencies on your system — start here if you are setting up OpenSTEF for the first time.

- **Quickstart** (:doc:`quickstart`)
   Run your first forecast in minutes using sample data, with minimal code and no prior OpenSTEF knowledge required.

- **Your First Forecast** (:doc:`first_forecast`)
   A step-by-step tutorial covering data preparation, model training, and generating predictions, with explanations of each stage in the workflow.

- **Backtesting Models** (:doc:`backtesting`)
   Learn how to evaluate and compare model performance using historical data before deploying a forecast pipeline.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend the library with custom data sources, feature engineering, and model configurations for power users with specific requirements.

.. note::

   New to OpenSTEF? Start with :doc:`installation`, then follow the :doc:`quickstart` to see a working forecast before diving into the full tutorial. If you are already familiar with the library and want to tailor it to your use case, jump directly to :doc:`advanced_customization`.
