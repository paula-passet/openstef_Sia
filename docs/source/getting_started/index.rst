Getting Started

This section walks you through installing OpenSTEF and running your first forecasts, from basic setup to advanced customization.

   Set up OpenSTEF on your system with the right packages for your needs—start here if this is your first time.

**Quickstart** (:doc:`quickstart`)
   Run your first forecast in under 5 minutes using sample data and minimal code.

**Your First Forecast** (:doc:`first_forecast`)
   Complete step-by-step tutorial explaining the full forecasting workflow from data preparation to model training.

**Backtesting Models** (:doc:`backtesting`)
   Evaluate and compare different model configurations using historical data to find the best approach.

**Advanced Customization** (:doc:`advanced_customization`)
   Extend OpenSTEF with custom data sources, feature engineering, and model configurations for power users.
