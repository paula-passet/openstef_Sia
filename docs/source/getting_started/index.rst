Getting Started
===============

This section takes you from a fresh install to running real forecasts with OpenSTEF, a modular Python library for short-term energy load forecasting. Whether you are new to the library or looking to extend it for advanced use cases, start with the page that matches your experience level.

- **Installation** (:doc:`installation`)
   Set up OpenSTEF and its dependencies on your system — start here if you have never used the library before.

- **Quickstart** (:doc:`quickstart`)
   Run your first forecast in minutes using sample data, with minimal setup and explanation.

- **Your First Forecast** (:doc:`first_forecast`)
   Step-by-step tutorial covering data preparation, model training, and generating predictions — recommended for users who want to understand the full workflow.

- **Backtesting Models** (:doc:`backtesting`)
   Evaluate and compare model performance using historical data to validate forecast quality before deploying.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend the library with custom data sources, feature engineering, and model configurations — aimed at experienced users with specific requirements.
