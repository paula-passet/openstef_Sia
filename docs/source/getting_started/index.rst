Getting Started
===============

Everything you need to go from a fresh install to running real forecasts with OpenSTEF, ordered from first steps to advanced usage.

- **Installation** (:doc:`installation`)
   Install the OpenSTEF library and its dependencies - start here if you are setting up for the first time.

- **Quickstart** (:doc:`quickstart`)
   Run your first forecast in under five minutes using sample data and minimal code.

- **Your First Forecast** (:doc:`first_forecast`)
   Step-by-step tutorial covering data preparation, model training, and generating predictions with full explanations.

- **Backtesting Models** (:doc:`backtesting`)
   Evaluate and compare model performance against historical data to validate your forecasting pipeline.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend OpenSTEF with custom data sources, features, and models for production use cases.

.. note::
   New to OpenSTEF? Start with :doc:`installation`, then follow :doc:`quickstart` to see the library in action before diving deeper.
