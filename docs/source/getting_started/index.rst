Getting Started

**Quickstart** (:doc:`quickstart`)
   Run your first forecast in under 5 minutes with sample data and minimal code.

**Your First Forecast** (:doc:`first_forecast`)
   Complete step-by-step tutorial walking through the full forecasting workflow with explanations.

**Backtesting Models** (:doc:`backtesting`)

**Advanced Customization** (:doc:`advanced_customization`)
   Extend the library with custom data sources, feature engineering, and model configurations.
