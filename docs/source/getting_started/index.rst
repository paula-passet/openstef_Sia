Getting Started
===============

This section takes you from a fresh install to running real energy forecasts with OpenSTEF, the open-source Python library for short-term energy forecasting.

- **Installation** (:doc:`installation`)
   Install the library and its dependencies — start here if you haven't set up OpenSTEF yet.

- **Quickstart** (:doc:`quickstart`)
   Get a working forecast running in under five minutes using sample data, with minimal explanation.

- **Your First Forecast** (:doc:`first_forecast`)
   A guided, step-by-step walkthrough of the full forecasting workflow — data preparation, model training, and generating predictions — with explanations at each stage.

- **Backtesting Models** (:doc:`backtesting`)
   Learn how to evaluate and compare models against historical data to validate forecast quality before deploying.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend the library with custom data sources, feature pipelines, and model configurations for production use cases.

.. note::

   New to OpenSTEF? Start with :doc:`installation`, then follow the :doc:`quickstart` to see the library in action. If you want a deeper understanding of how everything fits together, :doc:`first_forecast` walks through the same workflow with full explanations.
