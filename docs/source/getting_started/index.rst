Getting Started
===============

This section helps you get OpenSTEF running, from installation through your first forecasts.

**Installation** (:doc:`installation`)
   Set up OpenSTEF on your system with the packages you need - start here if this is your first time.

**Quickstart** (:doc:`quickstart`)
   Run your first forecast in under 5 minutes with minimal code and sample data.

**Your First Forecast** (:doc:`first_forecast`)
   Complete step-by-step tutorial explaining the full workflow from data preparation to prediction.

**Backtesting Models** (:doc:`backtesting`)
   Evaluate and compare different models using historical data to find the best approach for your use case.

**Advanced Customization** (:doc:`advanced_customization`)
   Extend the library with custom data sources, feature engineering, and model configurations for power users.
