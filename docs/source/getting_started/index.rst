Getting Started
===============

This section takes you from installing OpenSTEF to running your first forecasts, with tutorials suited to both newcomers and experienced users looking to go deeper.

- **Installation** (:doc:`installation`)
   Set up OpenSTEF and its packages on your system — start here if you haven't installed the library yet.

- **Quickstart** (:doc:`quickstart`)
   Run your first forecast in minutes using the preset workflow with minimal configuration.

- **Your First Forecast** (:doc:`first_forecast`)
   Step-by-step tutorial walking through the full forecasting workflow using the custom pipeline approach, with explanations at each stage.

- **Backtesting Models** (:doc:`backtesting`)
   Evaluate a trained model against historical data using the BEAM (Backtesting, Evaluation, Analysis and Metrics) library.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend OpenSTEF with custom data sources, feature engineering, and model configurations for production use cases.

.. note::

   **New to OpenSTEF?** Follow the pages in order: :doc:`installation` → :doc:`quickstart` → :doc:`first_forecast`.

   **Already installed?** Jump straight to :doc:`quickstart` or :doc:`first_forecast` depending on how much detail you want.

   **Evaluating model quality?** Go directly to :doc:`backtesting`.
