Getting Started
===============

This section takes you from installing the OpenSTEF library through running your first forecasts, with separate guides for every experience level.

- **Installation** (:doc:`installation`)
   Install the library on your system, including system requirements and optional dependencies — start here if you're new to OpenSTEF.

- **Quickstart** (:doc:`quickstart`)
   Run a working forecast in minutes using sample data, with minimal setup and no prior knowledge required.

- **Your First Forecast** (:doc:`first_forecast`)
   A complete step-by-step tutorial covering data preparation, model training, and generating predictions — ideal if you want to understand the full workflow before integrating OpenSTEF into your own project.

- **Backtesting Models** (:doc:`backtesting`)
   Learn how to evaluate and compare model performance against historical data to validate your forecasting setup.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend the library with custom data sources, feature engineering, and model configurations — aimed at users who are comfortable with the basics and want deeper control.

.. note::
   If you are completely new to OpenSTEF, follow the pages in order: **Installation → Quickstart → Your First Forecast**.
   Experienced users can jump directly to **Backtesting** or **Advanced Customization**.
