Getting Started
===============

This section helps you start using OpenSTEF, a Python library for short-term energy forecasting. Whether you're installing for the first time or building your first forecast model, you'll find the resources you need here.

If you're new to OpenSTEF, start with :doc:`installation` to set up the library on your system. This covers system requirements, package options, and platform-specific considerations to get you up and running quickly.

Once installed, :doc:`quickstart` provides the fastest path to generating your first forecast with a minimal working example using sample data. This single-page guide gets you from zero to a working forecast in minutes.

For a more detailed introduction, :doc:`first_forecast` walks you through creating a forecast step-by-step, explaining data preparation, model training, and prediction generation along the way. This tutorial helps you understand what's happening under the hood.

After you've created your first forecast, :doc:`backtesting` shows you how to evaluate and compare different models using historical data. Learn how to assess model performance and choose the best approach for your use case.

Finally, :doc:`advanced_customization` is for power users who want to extend the library's capabilities. This covers custom data pipelines, feature engineering, model implementations, and integration patterns for production environments.

Choose your starting point based on where you are: installation for setup, quickstart for immediate results, first forecast for understanding, backtesting for evaluation, or advanced customization for extending the library.
