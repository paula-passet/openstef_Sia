Getting Started
===============

Everything you need to go from a fresh install to running your first energy forecast with OpenSTEF.

**Installation** (:doc:`installation`)
   Install the library and verify your environment meets the system requirements — start here if you are new to OpenSTEF.

**Quickstart** (:doc:`quickstart`)
   Get a forecast running in minutes using the built-in preset workflows with minimal configuration.

**Your First Forecast** (:doc:`first_forecast`)
   Step-by-step tutorial that walks through building a forecast with the custom pipeline, with explanations of each stage.

**Backtesting Models** (:doc:`backtesting`)
   Evaluate a trained model against historical data to understand its accuracy before deploying it.

**Advanced Customization** (:doc:`advanced_customization`)
   Extend OpenSTEF with custom data sources, feature engineering, and model components for production use cases.
