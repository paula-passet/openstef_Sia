Getting Started
===============

This section helps you get OpenSTEF up and running, from installation through your first forecasts. Whether you're new to energy forecasting or an experienced practitioner, these pages will guide you from zero to working forecasts with minimal friction.

Start with :doc:`installation` to set up the library on your system, including system requirements and troubleshooting common issues. If you want the absolute fastest path to a working forecast, jump to :doc:`quickstart` for a minimal example that runs in minutes with sample data.

Once you're ready to understand the details, :doc:`first_forecast` walks through the complete forecasting workflow step-by-step, explaining data preparation, model training, and generating predictions. After you've created your first forecast, :doc:`backtesting` shows how to evaluate and compare different models using historical data to ensure your forecasts are reliable.

For power users who need to extend the library's capabilities, :doc:`advanced_customization` demonstrates how to implement custom data sources, feature engineering pipelines, and model components that integrate seamlessly with OpenSTEF's architecture.

Most users should follow the pages in order: installation, quickstart, then first forecast. Advanced users can skip directly to the topics they need.
