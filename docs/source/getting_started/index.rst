Getting Started
===============

This section takes you from installing the OpenSTEF library through running your first forecasts, with separate guides for beginners and experienced users.

- **Installation** (:doc:`installation`)
   Install the library on your system — start here if you haven't set up OpenSTEF yet, covering system requirements and optional dependencies.

- **Quickstart** (:doc:`quickstart`)
   The fastest path to a working forecast: a minimal, self-contained example using sample data that you can run in minutes.

- **Your First Forecast** (:doc:`first_forecast`)
   A step-by-step tutorial walking through data preparation, model training, and generating predictions — ideal if you want to understand the full workflow before diving deeper.

- **Backtesting Models** (:doc:`backtesting`)
   Learn how to evaluate and compare different models against historical data to validate forecast quality before deploying.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend the library with custom data sources, feature engineering, and model configurations — aimed at users already comfortable with the core workflow.

.. note::
   New to OpenSTEF? Follow the pages in order: **Installation → Quickstart → Your First Forecast**.
   Already familiar with the basics? Jump straight to **Backtesting** or **Advanced Customization**.
