Getting Started
===============

This section takes you from installing OpenSTEF through running your first forecasts, with tutorials suited to both new users and those looking to push the library further.

- **Installation** (:doc:`installation`)
   Install OpenSTEF on your system and verify your environment is ready — start here if you are new to the library.

- **Quickstart** (:doc:`quickstart`)
   Run your first forecast in minutes using sample data, with minimal setup and explanation.

- **Your First Forecast** (:doc:`first_forecast`)
   A step-by-step tutorial covering data preparation, model training, and generating predictions, with explanations of each stage.

- **Backtesting Models** (:doc:`backtesting`)
   Learn how to evaluate and compare models against historical data to build confidence before deploying forecasts.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend the library with custom data sources, features, and models — aimed at users already comfortable with the core workflow.

.. note::

   If you are completely new to OpenSTEF, follow the pages in order: **Installation → Quickstart → Your First Forecast**.
   If you have used the library before and want a specific topic, jump directly to the relevant page.
