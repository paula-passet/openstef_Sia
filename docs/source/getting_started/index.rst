Getting Started
===============

This section takes you from installing OpenSTEF to running production-ready forecasts, with guides suited to every experience level.

- **Installation** (:doc:`installation`)
   Install the library and verify your environment is ready — start here if you are new to OpenSTEF.

- **Quickstart** (:doc:`quickstart`)
   Run your first forecast in minutes using sample data, with minimal setup required.

- **Your First Forecast** (:doc:`first_forecast`)
   Follow a complete, explained walkthrough covering data preparation, model training, and generating predictions.

- **Backtesting Models** (:doc:`backtesting`)
   Learn how to evaluate and compare models against historical data to validate forecast quality.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend OpenSTEF with custom data sources, feature engineering, and model configurations for production use cases.

.. note::

   Not sure where to start? Follow this path:

   1. :doc:`installation` → :doc:`quickstart` — get something working fast.
   2. :doc:`first_forecast` — understand the full workflow before customising anything.
   3. :doc:`backtesting` and :doc:`advanced_customization` — once you are ready to go deeper.
