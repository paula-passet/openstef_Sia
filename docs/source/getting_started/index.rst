Getting Started
===============

Everything you need to go from a fresh install to running your first energy forecasts with OpenSTEF as a library in your own Python project.

- **Installation** (:doc:`installation`)
   Install OpenSTEF and its dependencies, including system requirements and optional extras.

- **Quickstart** (:doc:`quickstart`)
   Get a working forecast in minutes using the preset pipeline workflow — the fastest possible starting point.

- **Your First Forecast** (:doc:`first_forecast`)
   Step-by-step tutorial that walks through building a forecast with the custom pipeline, with explanations of each stage.

- **Backtesting Models** (:doc:`backtesting`)
   Evaluate a trained model against historical data to understand its accuracy before deploying it.

- **Advanced Customization** (:doc:`advanced_customization`)
   Extend OpenSTEF with custom data sources, feature engineering, and model configurations for production use cases.

----

**Not sure where to start?**

- New to OpenSTEF → :doc:`installation`, then :doc:`quickstart`
- Want to understand the full workflow → :doc:`first_forecast`
- Already have a model and want to validate it → :doc:`backtesting`
- Building a production integration → :doc:`advanced_customization`
