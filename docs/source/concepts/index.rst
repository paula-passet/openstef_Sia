Core Concepts
=============

This section explains the fundamental ideas behind short-term energy forecasting and OpenSTEF's design philosophy.

**Forecasting Basics** (:doc:`forecasting_basics`)
   Learn what short-term forecasting is, why it matters for grid operations, and how it differs from other prediction approaches.

**Quantiles and Confidence** (:doc:`quantiles_and_confidence`)
   Understand probabilistic forecasts and how to interpret uncertainty estimates in OpenSTEF predictions.

**Model Selection** (:doc:`model_selection`)
   Compare available forecasting models and learn when to use each type based on your data and requirements.

**Feature Engineering** (:doc:`feature_engineering`)
   Discover the key predictors OpenSTEF uses—weather data, temporal patterns, and domain-specific features for energy systems.

**Reliability and Fallback** (:doc:`reliability_and_fallback`)
   Ensure production stability with strategies for handling model failures, missing data, and edge cases.
