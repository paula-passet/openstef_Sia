OpenSTEF Documentation
======================

OpenSTEF is a Python machine learning library for short-term energy forecasting. It provides a complete framework for building probabilistic forecasts that predict energy loads hours to days ahead, helping utilities manage grid congestion, estimate transport capacity, and optimize energy operations.
