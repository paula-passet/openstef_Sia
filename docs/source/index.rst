OpenSTEF Documentation
======================

OpenSTEF is an open-source Python machine learning library for short-term energy forecasting. It provides complete pipelines for predicting electricity grid load hours to days ahead, helping grid operators manage congestion and optimize asset utilization. The library delivers probabilistic forecasts with uncertainty estimates for energy consumption, renewable generation, and combined load scenarios.

Community
---------

OpenSTEF is developed openly on `GitHub <https://github.com/OpenSTEF/openstef>`_ where you can report issues, request features, and contribute code. Join our community meetings held every four weeks to discuss progress and collaboration opportunities - meeting details are available on our `LFE wiki page <https://wiki.lfenergy.org/display/OS/Four-weekly+community+meeting>`_.
