OpenSTEF Documentation
======================

OpenSTEF is a Python machine learning library for creating short-term energy forecasts. It provides a complete pipeline for training models and generating predictions for energy grid applications, from data preprocessing and feature engineering to model training and forecast evaluation.

Community
---------

OpenSTEF is an open source project hosted on `GitHub <https://github.com/OpenSTEF/openstef>`_. Join our community discussions in the `OpenSTEF Teams channel <https://teams.microsoft.com/l/team/19%3ac08a513650524fc988afb296cd0358cc%40thread.tacv2/conversations?groupId=bfcb763a-3a97-4938-81d7-b14512aa537d&tenantId=697f104b-d7cb-48c8-ac9f-bd87105bafdc>`_ for questions, support, and collaboration.
