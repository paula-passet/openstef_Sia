Who is it for?
==============

OpenSTEF is aimed at data scientists, ML engineers, and energy domain experts who need
reliable short-term forecasts — hours to days ahead — for use cases such as grid
congestion management, transport forecasting, EV charging capacity estimation, and
grid loss prediction. It assumes familiarity with Python and basic machine learning
concepts, but no prior energy-domain expertise is required.

Getting started
===============

If you are new to OpenSTEF, the best place to begin is the **User Guide**, which walks
you through installation, core concepts, and your first forecast. The **Examples**
section provides runnable notebooks that demonstrate common workflows end-to-end.

Once you are comfortable with the basics, the **API Reference** gives complete
documentation for every public class and function in the library. If you want to extend
OpenSTEF or contribute back to the project, the **Contributing** guide explains the
development workflow and contribution guidelines.

Install
=======

.. code-block:: bash

   pip install openstef

For alternative package managers and detailed setup instructions, see the
:doc:`user_guide/installation` page.

Community & support
===================

OpenSTEF is a community-driven project and contributions of all kinds are welcome.

- **Bug reports & feature requests** — use the `GitHub issue tracker <https://github.com/OpenSTEF/openstef/issues>`_
- **Source code** — `github.com/OpenSTEF/openstef <https://github.com/OpenSTEF/openstef>`_
- **Linux Foundation project page** — `lfenergy.org/projects/openstef <https://www.lfenergy.org/projects/openstef/>`_
- **PyPI package** — `pypi.org/project/openstef <https://pypi.org/project/openstef/>`_
