OpenSTEF Documentation
======================

OpenSTEF is a Python machine learning library for short-term energy forecasting in the electricity grid. It provides a complete framework for building forecasting pipelines that predict energy loads hours to days ahead, helping utilities manage grid congestion, estimate transport capacity, and optimize energy distribution. OpenSTEF is a library that you integrate into your own applications, not a standalone forecasting application.

Community
---------

OpenSTEF is developed and maintained by an active open source community. You can find the source code and contribute to the project on `GitHub <https://github.com/OpenSTEF/openstef>`_. For questions, discussions, and community support, join our Teams channel where community members and maintainers help answer questions and discuss OpenSTEF development.
