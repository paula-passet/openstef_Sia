OpenSTEF Documentation
======================

OpenSTEF is a Python machine learning library for short-term energy forecasting. It provides a complete pipeline for training models and generating probabilistic forecasts hours to days ahead, designed specifically for energy sector applications like congestion management, grid loss prediction, and transport forecasts. OpenSTEF is a library, not a full-stack application—you integrate it into your own systems and workflows.

Community
---------

OpenSTEF is an open-source project under LF Energy. Join the **#openstef channel** in the `LF Energy Slack workspace <https://slack.lfenergy.org/>`_ to ask questions and connect with other users. If you need an invitation, email openstef@lfenergy.org. Report bugs and request features through the `GitHub issue tracker <https://github.com/OpenSTEF/openstef/issues>`_. The project also hosts four-weekly community meetings—check the `LF Energy wiki <https://wiki.lfenergy.org/display/OS/Four-weekly+community+meeting>`_ for meeting details and how to join.
