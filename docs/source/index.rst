OpenSTEF is a Python library for short-term energy forecasting, not a deployable application or pre-trained model. It provides the tools and components needed to build energy forecasting applications. The library is designed around pipelines that offer functionality for training models, generating forecasts, and evaluating forecasting performance. It includes components for data validation, feature engineering, and machine learning operations. OpenSTEF 4.0 represents a major architectural refactor focused on modularity, type safety, extensibility, and improved documentation. It is currently in alpha release with feature parity to OpenSTEF V3 and is being used in production for congestion management at over 10,000 grid locations.
