OpenSTEF Documentation
======================

OpenSTEF is a Python machine learning library for creating short-term energy forecasts. It provides complete pipelines for data preprocessing, feature engineering, model training, forecasting, and evaluation - everything needed to build production-ready energy forecasting systems. The library is designed for energy sector professionals who need accurate load predictions hours to days ahead.

Community
---------

OpenSTEF is an open source project hosted on `GitHub <https://github.com/OpenSTEF/openstef>`_. Join our community through the `LF Energy Slack workspace <https://slack.lfenergy.org/>`_ (#openstef channel) or attend our four-weekly community meetings. For bug reports and feature requests, use the `GitHub issue tracker <https://github.com/OpenSTEF/openstef/issues>`_. Additional support options and meeting details are available on our support page.
