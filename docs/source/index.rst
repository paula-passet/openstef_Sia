OpenSTEF Documentation
======================

OpenSTEF is a Python machine learning library for short-term energy forecasting. It provides tools to train models, generate forecasts, and evaluate predictions for energy systems. The library is designed for grid operators, energy companies, and researchers who need reliable forecasts for operational planning.

Community
---------

OpenSTEF is an open source project hosted on `GitHub <https://github.com/OpenSTEF/openstef>`_. For questions and support, join our Slack channel by emailing openstef@lfenergy.org. Report bugs or request features through the `GitHub issue tracker <https://github.com/OpenSTEF/openstef/issues>`_. Join our four-weekly community meetings to connect with other users and contributors—find meeting details on our `wiki page <https://wiki.lfenergy.org/display/OS/Four-weekly+community+meeting>`_.
