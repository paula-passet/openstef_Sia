OpenSTEF Documentation
======================

OpenSTEF is a Python machine learning library for short-term energy forecasting in the electricity grid. It provides a complete framework for building probabilistic forecasts hours to days ahead, helping utilities manage grid congestion, predict transport loads, and estimate available capacity. OpenSTEF is designed as a library that integrates into your existing data infrastructure and workflows, not a standalone application.
