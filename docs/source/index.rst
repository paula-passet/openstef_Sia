Welcome to OpenSTEF
===================

OpenSTEF is a Python library for creating short-term energy forecasts. It provides a complete machine learning pipeline—from data preprocessing and feature engineering to model training, forecasting, and evaluation—specifically designed for the energy sector. Whether you're forecasting load at substations, predicting grid losses, or managing congestion, OpenSTEF delivers probabilistic forecasts with uncertainty estimates to support operational decision-making.

Who is OpenSTEF for?
--------------------

OpenSTEF serves grid operators, energy researchers, and data scientists working on short-term energy forecasting challenges. If you need to predict electricity demand or generation hours to days ahead, OpenSTEF provides the tools and domain expertise to build production-ready forecasting systems. The library is model-agnostic and extensible, making it suitable for both research experimentation and enterprise integration.

Getting Started
---------------

New users should begin with the **User Guide**, which covers installation across multiple package managers and walks through a quick start example. The guide then progresses to tutorials that demonstrate core workflows like training models, generating forecasts, and evaluating results.

For those seeking specific solutions, the **How-To Guides** provide focused recipes for common tasks—from handling missing data to customizing feature engineering for your domain. When you need detailed technical specifications, the **API Reference** documents every function, class, and parameter.

The **Explanation** section offers deeper context on OpenSTEF's architecture, design decisions, and the forecasting techniques it implements. This material helps you understand not just how to use the library, but why it works the way it does.

Community and Support
---------------------

OpenSTEF is an open-source project under LF Energy. Development happens on `GitHub <https://github.com/OpenSTEF/openstef>`_, where you can report bugs, request features, and contribute code or documentation. The community meets regularly to discuss progress and collaboration—details are available in the `community meetings documentation <https://wiki.lfenergy.org/display/OS/Biweekly+Refinement>`_.

For project updates and roadmap information, visit the `OpenSTEF project page <https://www.lfenergy.org/projects/openstef/>`_ at LF Energy.
