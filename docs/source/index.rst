OpenSTEF Documentation
======================

OpenSTEF is a Python library for short-term energy forecasting. It automates the machine learning pipeline for predicting energy loads and generation, handling everything from feature engineering and model training to producing multi-horizon forecasts. OpenSTEF is an open-source project under the `LF Energy <https://www.lfenergy.org/projects/openstef/>`_ umbrella.

Who Is This For?
----------------

OpenSTEF is designed for data scientists, energy system engineers, and software developers working in the energy sector. Whether you operate a distribution grid, manage renewable generation assets, or build energy analytics platforms, OpenSTEF provides the forecasting building blocks you can integrate into your own systems. As a library, it gives you full control — you supply the data, configure the models, and decide how to use the results.

Where to Start
--------------

If you're new to OpenSTEF, begin with the **Getting Started** guide, which walks you through installation and your first forecast. For a deeper understanding of the forecasting concepts and how OpenSTEF approaches them, the **User Guide** covers topics like feature engineering, model training, and prediction pipelines. Developers looking to understand the internals or extend the library should consult the **API Reference** for detailed module and class documentation. If you're interested in the energy domain itself, the **Intro to Energy Forecasting** section provides useful background.

Community and Support
---------------------

OpenSTEF is developed in the open and welcomes contributions of all kinds — bug reports, documentation improvements, and new features alike.

- **Source code & issues:** `GitHub <https://github.com/OpenSTEF/openstef>`_
- **Contributing:** See the contributing guide for development workflow and guidelines
- **LF Energy:** `Project page <https://www.lfenergy.org/projects/openstef/>`_

If you encounter a bug or have a feature request, please open an issue on the `GitHub issue tracker <https://github.com/OpenSTEF/openstef/issues>`_. For questions about usage, GitHub Discussions is the best place to connect with the community and maintainers.
