Welcome to OpenSTEF
===================

OpenSTEF is a Python machine learning library for short-term energy forecasting. It provides tools to build accurate forecasts of energy demand and supply, helping grid operators and energy companies maintain grid stability and optimize operations.

Who is OpenSTEF for?
---------------------

OpenSTEF is designed for data scientists, engineers, and researchers working in the energy sector. Whether you're at a distribution system operator managing grid balance, an energy company optimizing trading strategies, or a research institution exploring forecasting methods, OpenSTEF provides the building blocks you need.

Getting Started
---------------

If you're new to OpenSTEF, begin with the installation guide to set up the library in your Python environment. Once installed, the quickstart tutorial walks you through creating your first forecast using sample data.

For those wanting to understand the methodology behind OpenSTEF, the concepts section explains how the library approaches feature engineering, model training, and multi-horizon forecasting. The user guide provides detailed documentation on each component, from data preparation to model evaluation.

The API reference offers complete technical documentation of all classes and functions. If you're integrating OpenSTEF into production systems, the deployment guide covers best practices and common patterns.

Contributing and Support
------------------------

OpenSTEF is an open source project hosted by LF Energy. We welcome contributions of all kinds—from bug reports and documentation improvements to new features and research implementations.

For questions and discussions, visit our GitHub repository at https://github.com/OpenSTEF/openstef. Report bugs or request features through the GitHub issue tracker. Learn more about the project and community at the LF Energy project page: https://www.lfenergy.org/projects/openstef/

The contributing guide explains how to set up a development environment and submit changes. All community members are expected to follow our code of conduct.
