OpenSTEF Documentation
======================

OpenSTEF is a Python machine learning library for short-term energy forecasting. It provides a complete framework for predicting electricity grid load hours to days ahead, helping grid operators manage congestion and optimize asset utilization. The library includes all components needed for the machine learning pipeline: data preprocessing, feature engineering, model training, forecasting, and evaluation.
