OpenSTEF Documentation
======================

OpenSTEF is a Python machine learning library for creating short-term energy forecasts. It provides a complete pipeline for training models, generating predictions, and evaluating results across various energy sector applications. The library is designed for data scientists and engineers who need reliable, production-ready forecasting capabilities for electrical grids, renewable energy systems, and energy management.

Community
---------

OpenSTEF is an open source project hosted on `GitHub <https://github.com/OpenSTEF/openstef>`_. Join our community through the `OpenSTEF Teams channel <https://teams.microsoft.com/l/team/19%3ac08a513650524fc988afb296cd0358cc%40thread.tacv2/conversations?groupId=bfcb763a-3a97-4938-81d7-b14512aa537d&tenantId=697f104b-d7cb-48c8-ac9f-bd87105bafdc>`_ for questions and discussions. We hold four-weekly community meetings that are open to everyone - find meeting details on our `wiki page <https://wiki.lfenergy.org/display/OS/Four-weekly+community+meeting>`_. For bug reports and feature requests, please use the `GitHub issue tracker <https://github.com/OpenSTEF/openstef/issues>`_.
