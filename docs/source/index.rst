Welcome to OpenSTEF
===================

OpenSTEF is a Python machine learning library for short-term energy forecasting. It provides complete pipelines for data preprocessing, feature engineering, model training, forecasting, and evaluation—everything needed to generate accurate probabilistic forecasts hours to days ahead. Built with domain expertise from the energy sector, OpenSTEF includes specialized features for solar generation estimation, load patterns, and grid-specific transformations.

Who is OpenSTEF for?
---------------------

OpenSTEF is designed for energy grid operators, utilities, researchers, and data scientists working on energy forecasting challenges. Whether you're managing grid congestion, planning EV charging infrastructure, estimating grid losses, or conducting research on energy systems, OpenSTEF provides the tools to build production-ready forecasting solutions. The library is model-agnostic and works with both classical machine learning approaches and deep learning methods.

Getting started
---------------

If you're new to OpenSTEF, begin with the User Guide to understand core concepts and installation. The Quick Start tutorial walks through creating your first forecast in minutes. For specific tasks like feature engineering or model training, the How-To Guides provide focused recipes. The API Reference documents every function and class in detail. 

When you're ready to contribute or customize OpenSTEF for your needs, the Contributing section explains how to get involved with code, documentation, or community building.

Community and support
---------------------

OpenSTEF is an open-source project hosted by LF Energy. Join the community on the `OpenSTEF Slack workspace <https://lfenergy.slack.com/>`_ to ask questions and share experiences. Report bugs or request features through the `GitHub issue tracker <https://github.com/OpenSTEF/openstef/issues>`_. The community holds bi-weekly meetings open to all participants—check the project page at `openstef.org <https://openstef.org>`_ for details.

For benchmark datasets and examples, explore the `Alliander Energy Forecasting Benchmark <https://github.com/alliander-opensource/short-term-forecasting-benchmark>`_ on GitHub.
