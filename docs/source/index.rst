OpenSTEF Documentation
======================

OpenSTEF is a Python machine learning library for short-term energy forecasting. It provides tools to train models and generate forecasts for electricity load, solar generation, and other energy-related time series, with a focus on distribution grid operations. The library is designed for data scientists and engineers at grid operators, energy companies, and research institutions who need reliable forecasts from hours to days ahead.

Community
---------

OpenSTEF is an open-source project maintained by Alliander and the community. You can find the source code, report issues, and contribute on `GitHub <https://github.com/OpenSTEF/openstef>`_. For questions and discussions, join the OpenSTEF Teams channel or open a GitHub issue. We welcome contributions, bug reports, and feedback from users at all experience levels.
