Who is it for?
==============

OpenSTEF is built for data scientists, ML engineers, and researchers working on
energy grid applications. Whether you are managing grid congestion, estimating EV
charging capacity, or predicting grid losses, OpenSTEF gives you domain-aware
tooling that understands energy data out of the box.

Getting started
===============

If you are new to OpenSTEF, the **User Guide** is the best place to begin. It walks
you through installation, explains core concepts such as prediction jobs and
pipelines, and includes worked examples you can run immediately. Once you are
comfortable with the fundamentals, the **API Reference** provides complete
documentation for every public class and function in the library. Practical
**Examples** show end-to-end notebooks covering common forecasting scenarios.

Install with pip in seconds:

.. code-block:: bash

   pip install openstef

Community & support
===================

OpenSTEF is developed in the open under the LF Energy umbrella. The fastest way to
get help is the **#openstef** channel on the
`LF Energy Slack workspace <https://slack.lfenergy.org/>`_. For bugs and feature
requests, use the `GitHub issue tracker <https://github.com/OpenSTEF/openstef/issues>`_.
The project also hosts four-weekly community meetings — details and invite links are
on the `OpenSTEF wiki <https://wiki.lfenergy.org/display/OS/Four-weekly+community+meeting>`_.

Contributions of all kinds are welcome. See the **Contributing** section to learn
how to get involved, and reach out at `openstef@lfenergy.org <mailto:openstef@lfenergy.org>`_
if you need a Slack invitation.
