Who is it for?
--------------

OpenSTEF is aimed at **data scientists and engineers** working in the energy sector who
need reliable short-term load forecasts — for congestion management, transport planning,
EV charging capacity, or grid loss prediction. It assumes familiarity with Python and
basic machine learning concepts, but handles the energy-domain complexity for you.

Getting started
---------------

If you are new to OpenSTEF, the **User Guide** is the right place to begin. It walks
through installation, explains core concepts such as prediction jobs and pipelines, and
provides worked examples you can run immediately. Once you are comfortable with the
basics, the **API reference** gives complete, precise documentation for every public
class and function in the library. The **Examples** section collects runnable notebooks
that demonstrate common forecasting workflows end to end.

Install OpenSTEF now with:

.. code-block:: bash

   pip install openstef

Community and support
---------------------

OpenSTEF is a `Linux Foundation Energy <https://www.lfenergy.org/projects/openstef/>`_
project developed in the open. If you find a bug or want to request a feature, open an
issue on the `GitHub issue tracker <https://github.com/OpenSTEF/openstef/issues>`_.
Contributions of all kinds are welcome — see the **Contributing** section for how to
get involved. You can also reach the team at openstef@lfenergy.org.
