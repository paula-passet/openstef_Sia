Welcome to OpenSTEF
===================

OpenSTEF is a Python machine learning library for short-term energy forecasting. It provides the tools to build, train, and deploy forecasting models that predict energy supply, demand, and prices from minutes to days ahead. Originally developed by Alliander and Stedin, two Dutch grid operators, OpenSTEF automates the complete machine learning pipeline—from feature engineering to model selection to forecast generation.

Who is OpenSTEF for?
---------------------

OpenSTEF is designed for energy professionals who need reliable forecasts to operate the grid safely and efficiently. Grid operators use it to predict load and generation, helping them balance supply and demand in real time. Energy traders rely on it to anticipate price movements and optimize their positions. Researchers and data scientists working in the energy sector will find it a practical foundation for experimenting with forecasting methods tailored to energy systems.

Getting started
---------------

If you're new to OpenSTEF, begin with the installation guide to set up the library in your Python environment. The quickstart tutorial walks you through creating your first forecast using sample data, introducing the core concepts and workflow. Once you're comfortable with the basics, explore the user guide for detailed explanations of feature engineering, model training, and forecast generation. The API reference provides comprehensive documentation of all classes and functions.

For those interested in the theory behind the forecasts, the concepts section explains the machine learning techniques and domain-specific approaches that power OpenSTEF. If you want to extend the library or contribute improvements, the developer guide covers the codebase architecture and contribution workflow.

Community and support
---------------------

OpenSTEF is an open-source project hosted by LF Energy, part of the Linux Foundation. The source code lives on GitHub at https://github.com/OpenSTEF/openstef, where you can report issues, request features, and contribute code. For project updates and background, visit the LF Energy project page at https://www.lfenergy.org/projects/openstef/. We welcome contributions from the community—whether you're fixing bugs, improving documentation, or adding new features.
