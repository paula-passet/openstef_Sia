Getting Started
===============

This section takes you from zero to running forecasts, whether you're installing OpenSTEF for the first time or migrating from a previous version.

**Installation** (:doc:`installation`)
   Install OpenSTEF and its packages, configure optional dependencies, and verify your setup.

**Quickstart** (:doc:`tutorials/forecasting_with_workflow_presets`)
   Run your first energy forecast using workflow presets and sample data in just a few minutes.

**Migrating from V3 to V4** (:doc:`migration_v3_v4`)
   Understand the architectural changes in V4 and update your existing code to the new modular structure.
