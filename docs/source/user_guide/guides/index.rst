Guides

Step-by-step instructions for common OpenSTEF tasks. Use these pages to answer "how do I..." questions about building and running forecasting pipelines.

**Forecasting** (:doc:`forecasting`)
   Configure and run forecasting pipelines — from model setup through training and prediction.

**Feature Engineering** (:doc:`feature_engineering`)
   Add transforms like holiday features, lag variables, and datetime encodings to improve forecast accuracy.

**Datasets** (:doc:`datasets`)
   Work with time series data structures, including validated datasets and versioned data for realistic backtesting.
