User Guide
==========

This section covers practical implementation topics to help you integrate OpenSTEF into your forecasting workflows. Whether you're deploying your first model or migrating from an earlier version, you'll find guidance on connecting data sources, running predictions in production, and configuring the library for your environment.

What you'll learn
-----------------

- Common forecasting scenarios and how to implement them
- Production deployment strategies from simple scripts to orchestrated pipelines
- Connecting OpenSTEF to various data sources and storage systems
- Migrating existing forecasts from OpenSTEF V3 to V4
- Configuring logging for monitoring and debugging

Guide to this section
---------------------

**Use Cases**: Practical examples for common forecasting scenarios including congestion management, load forecasting, and renewable energy prediction.

**Deployment**: Production deployment patterns covering scheduling approaches, containerization, and integration with orchestration platforms.

**Data Integration**: Connect OpenSTEF to your data infrastructure with examples for S3, Databricks, InfluxDB, PostgreSQL, and custom sources.

**Migration from V3 to V4**: Step-by-step guide for upgrading existing implementations, covering breaking changes and updated APIs.

**Logging**: Configure logging levels, add custom handlers, and integrate with monitoring systems for production observability.
