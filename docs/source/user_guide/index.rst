User Guide
==========

Practical guidance for integrating OpenSTEF into your workflows, from connecting data sources to running forecasts in production.

**Use Cases** (:doc:`use_cases`)
   Explore concrete forecasting scenarios — congestion management, transport forecasts, and grid losses — with working examples to adapt for your own grid.

**Deployment** (:doc:`deployment`)
   Patterns for running OpenSTEF in production, from simple scheduled scripts to containerised pipelines and enterprise integrations.

**Data Integration** (:doc:`data_integration`)
   Connect OpenSTEF to your data infrastructure — S3, Databricks, InfluxDB, PostgreSQL, or a custom source — and understand the expected input formats.

**Migrating from V3 to V4** (:doc:`migration_v3_v4`)
   Understand the breaking changes in V4, updated APIs, and how to update existing code when upgrading from OpenSTEF 3.x.
