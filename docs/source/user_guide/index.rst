User Guide
==========

This section covers practical implementation patterns for integrating OpenSTEF into your forecasting workflows—from common use cases to production deployment.

**Common Use Cases** (:doc:`use_cases`)
   Practical examples for congestion forecasting, transport forecasting, and other energy prediction scenarios.

**Production Deployment** (:doc:`deployment`)
   Deployment patterns from simple scheduled scripts to enterprise pipeline integration.

**Data Integration** (:doc:`data_integration`)
   Connect OpenSTEF to your data sources—S3, Databricks, InfluxDB, PostgreSQL, or custom backends.

**Migration from V3 to V4** (:doc:`migration_v3_v4`)
   Breaking changes, updated APIs, and step-by-step guidance for upgrading existing implementations.

**Logging Configuration** (:doc:`logging`)
   Configure log levels, custom handlers, and integrate OpenSTEF logging with your monitoring infrastructure.
