User Guide
==========

Practical guides for integrating OpenSTEF into your energy forecasting workflows, from common use cases to production deployment.

**Common Use Cases** (:doc:`use_cases`)
   Practical examples for congestion forecasts, transformer monitoring, and other typical applications.

**Data Integration** (:doc:`data_integration`)
   Connect OpenSTEF to your data sources including S3, Databricks, InfluxDB, PostgreSQL, and custom systems.

**Deployment** (:doc:`deployment`)
   Production deployment patterns from simple scheduled jobs to cloud-native architectures.

**Logging** (:doc:`logging`)
   Configure logging levels, custom handlers, and integrate with monitoring systems.

**Migration from V3 to V4** (:doc:`migration_v3_v4`)
   Upgrade guide covering breaking changes, updated APIs, and package structure differences.
