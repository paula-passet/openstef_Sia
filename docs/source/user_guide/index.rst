User Guide
==========

This section covers practical implementation topics for using OpenSTEF as a library in your own
projects — from integrating your data sources to deploying forecasting pipelines in production.

- **Use Cases** (:doc:`use_cases`)
     Explore concrete forecasting scenarios — congestion management, transport forecasts, grid losses,
     and more — with worked examples showing how to apply OpenSTEF to each.

- **Deployment** (:doc:`deployment`)
     Production deployment patterns for the OpenSTEF library, from simple scheduled scripts to
     containerised pipelines and enterprise integrations.

- **Data Integration** (:doc:`data_integration`)
     Connect OpenSTEF to your data sources — S3, Databricks, InfluxDB, PostgreSQL, and custom
     backends — using the library's flexible data interfaces.

- **Migrating from V3 to V4** (:doc:`migration_v3_v4`)
     Breaking changes, updated APIs, and a step-by-step migration path for upgrading existing
     OpenSTEF V3 code to the V4 architecture.
