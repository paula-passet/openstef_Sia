User Guide
==========

Practical guides for integrating OpenSTEF into your forecasting workflows and production systems.

**Common Use Cases** (:doc:`use_cases`)
   Real-world examples including congestion forecasts, load prediction, and solar generation.

**Deployment Patterns** (:doc:`deployment`)
   Production deployment approaches from simple scheduled scripts to cloud-native architectures.

**Data Integration** (:doc:`data_integration`)
   Connect OpenSTEF to your data sources: S3, Databricks, InfluxDB, PostgreSQL, or custom backends.

**Migration Guide (V3 to V4)** (:doc:`migration_v3_v4`)
   Upgrade from OpenSTEF 3.x with step-by-step instructions for breaking changes and new APIs.

**Logging Configuration** (:doc:`logging`)
   Set up logging for production: configure levels, add custom handlers, and integrate with monitoring systems.
