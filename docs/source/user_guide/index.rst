User Guide
==========

This section helps you put OpenSTEF into practice. Once you understand the basics of energy forecasting and how to use the library's core features, these guides show you how to integrate OpenSTEF into your workflow, deploy it in production, and handle real-world scenarios.

What You'll Learn
-----------------

These guides cover the practical aspects of working with OpenSTEF as a library:

- How to structure forecasting solutions for different energy grid scenarios
- Deployment patterns for production environments
- Integrating OpenSTEF with your existing data infrastructure
- Migrating from previous versions
- Configuring logging for operational visibility

Quick Guide to Topics
----------------------

**Use Cases**
   Common forecasting scenarios with practical examples: transformer congestion forecasts, grid planning, and demand response applications.

**Deployment**
   Production deployment patterns covering scheduled batch forecasting, containerized services, and cloud-native architectures.

**Data Integration**
   Connect OpenSTEF to your data sources: S3, Databricks, InfluxDB, PostgreSQL, or custom backends.

**Migration from V3 to V4**
   Breaking changes, updated APIs, and package structure changes when upgrading from OpenSTEF 3.x to 4.0.

**Logging**
   Configure logging levels, custom handlers, and integration with monitoring systems for production observability.
