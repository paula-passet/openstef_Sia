User Guide
==========

The User Guide covers everything you need to use OpenSTEF effectively, from installation and first steps through to advanced workflows and real-world examples.

**Getting Started** (:doc:`getting_started/index`)
   Install OpenSTEF, run your first forecast, and understand the basic workflow.

**Core Concepts** (:doc:`concepts/index`)
   Learn the key abstractions — datasets, models, horizons, quantiles, and the forecasting pipeline.

**How-To Guides** (:doc:`guides/index`)
   Task-oriented recipes for common operations like training models, generating probabilistic forecasts, and evaluating performance.

**Examples** (:doc:`examples/index`)
   Complete, runnable examples demonstrating end-to-end forecasting scenarios with real energy data.
