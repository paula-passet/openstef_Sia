User Guide
==========

This section covers practical implementation topics for using OpenSTEF as a library in your own
projects — from integrating data sources and deploying pipelines to handling real-world use cases.

- **Use Cases** (:doc:`use_cases`)
     Explore concrete forecasting scenarios — congestion management, transport forecasts, grid losses,
     and more — with worked examples showing how to apply OpenSTEF to each.

- **Deployment** (:doc:`deployment`)
     Production deployment patterns for running OpenSTEF pipelines, from simple scheduled scripts to
     containerised and enterprise-scale setups.

- **Data Integration** (:doc:`data_integration`)
     Connect OpenSTEF to your data sources — S3, Databricks, InfluxDB, PostgreSQL, and custom backends
     — using the library's flexible data interfaces.

- **Migrating from V3 to V4** (:doc:`migration_v3_v4`)
     Understand the breaking changes introduced in V4, update your imports and API calls, and adapt
     to the new modular architecture.
