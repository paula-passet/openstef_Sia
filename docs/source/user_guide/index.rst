User Guide
==========

Practical guidance for integrating OpenSTEF into your workflows, from connecting data sources to running forecasts in production.

**Use Cases** (:doc:`use_cases`)
   Explore concrete forecasting scenarios — congestion management, transport forecasts, and grid losses — with working examples to adapt for your own use case.

**Deployment** (:doc:`deployment`)
   Production deployment patterns covering scheduled pipelines, containerised setups, and enterprise integration approaches.

**Data Integration** (:doc:`data_integration`)
   Connect OpenSTEF to your data infrastructure — S3, Databricks, InfluxDB, PostgreSQL, or a custom source — with ready-to-use patterns.

**Migrating from V3 to V4** (:doc:`migration_v3_v4`)
   Understand the breaking changes in V4, updated APIs, and how to update existing code to work with the new modular architecture.
