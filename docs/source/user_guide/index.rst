User Guide
==========

This section covers practical implementation topics for working with OpenSTEF in real projects — from integrating your data sources to deploying forecasts in production.

**Use Cases** (:doc:`use_cases`)
   Explore concrete forecasting scenarios — congestion management, transport forecasts, grid losses, and more — with practical examples showing how to configure OpenSTEF for each.

**Deployment** (:doc:`deployment`)
   Understand production deployment patterns, from simple scheduled scripts to containerised pipelines, and choose the approach that fits your infrastructure.

**Data Integration** (:doc:`data_integration`)
   Connect OpenSTEF to your data sources — S3, Databricks, InfluxDB, PostgreSQL, or a custom backend — and learn how to structure inputs for the forecasting pipeline.

**Migrating from V3 to V4** (:doc:`migration_v3_v4`)
   Understand the breaking changes in V4, updated APIs, and revised package structure so you can upgrade an existing V3 project with confidence.
