User Guide
==========

Practical guidance for integrating OpenSTEF into your own systems and workflows — covering everything from connecting your data sources to running the library in production.

- **Use Cases** (:doc:`use_cases`)
   Explore concrete forecasting scenarios — congestion management, transport forecasts, and grid losses — with worked examples to help you map OpenSTEF to your own problem.

- **Deployment** (:doc:`deployment`)
   Learn production deployment patterns for the library, from simple scheduled scripts to containerised pipelines and enterprise integrations.

- **Data Integration** (:doc:`data_integration`)
   Connect OpenSTEF to your data infrastructure — S3, Databricks, InfluxDB, PostgreSQL, and custom sources — using the library's flexible data interfaces.

- **Migration Guide: V3 → V4** (:doc:`migration_v3_v4`)
   Understand the breaking changes in V4, updated APIs, and how to adapt existing V3 code to the new modular architecture.

- **Logging** (:doc:`logging`)
   Configure log levels, attach custom handlers, and integrate OpenSTEF's logging with your existing observability stack.
