User Guide
==========

This section covers practical implementation topics for integrating and operating OpenSTEF as a library
in your own systems and workflows.

- **Use Cases** (:doc:`use_cases`)
   Explore concrete forecasting scenarios — congestion management, transport forecasts, and grid losses — with working examples to adapt for your own use case.

- **Deployment** (:doc:`deployment`)
   Patterns for running OpenSTEF in production, from simple scheduled scripts to containerised pipelines and enterprise integrations.

- **Data Integration** (:doc:`data_integration`)
   Connect OpenSTEF to your data sources — S3, Databricks, InfluxDB, PostgreSQL, and custom backends — with ready-to-use integration patterns.

- **Migrating from V3 to V4** (:doc:`migration_v3_v4`)
   Understand the breaking changes in the V4 release and follow a step-by-step guide to update your existing code and configuration.
