User Guide
==========

This section covers practical implementation topics for using OpenSTEF as a library in your own
Python projects — from integrating data sources and deploying forecasting pipelines to handling
real-world use cases.

- **Use Cases** (:doc:`use_cases`)
   Explore concrete forecasting scenarios — congestion management, transport forecasts, grid losses,
   and more — with worked examples showing how to apply OpenSTEF to each.

- **Deployment** (:doc:`deployment`)
   Patterns for running OpenSTEF in production, from simple scheduled scripts to containerised
   and enterprise pipeline integrations.

- **Data Integration** (:doc:`data_integration`)
   Connect OpenSTEF to your data sources — S3, Databricks, InfluxDB, PostgreSQL, or a custom
   backend — and understand the expected input formats.

- **Migrating from V3 to V4** (:doc:`migration_v3_v4`)
   Understand the breaking changes introduced in V4, updated APIs, and how to adapt existing
   code to the new modular architecture.
