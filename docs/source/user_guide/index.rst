User Guide
==========

This section covers practical implementation topics for integrating and operating OpenSTEF as a library
in your own systems — from connecting data sources to deploying forecasting pipelines in production.

- **Use Cases** (:doc:`use_cases`)
   Explore concrete forecasting scenarios — congestion management, transport forecasts, and grid losses — with worked examples showing how to configure OpenSTEF for each.

- **Deployment** (:doc:`deployment`)
   Patterns for running OpenSTEF in production, from simple scheduled scripts to containerised and enterprise pipeline integrations.

- **Data Integration** (:doc:`data_integration`)
   Connect OpenSTEF to your data infrastructure — S3, Databricks, InfluxDB, PostgreSQL, and custom sources — with reusable integration patterns.

- **Migrating from V3 to V4** (:doc:`migration_v3_v4`)
   Breaking changes, updated APIs, and a step-by-step migration path for upgrading existing V3 codebases to the V4 architecture.
