User Guide
==========

Practical guidance for integrating OpenSTEF into your workflows, from connecting data sources to running
forecasts in production.

**Use Cases** (:doc:`use_cases`)
   Concrete examples of common forecasting scenarios — congestion management, transport forecasts, and
   grid losses — with code showing how to configure and run each.

**Deployment** (:doc:`deployment`)
   Production deployment patterns for running OpenSTEF reliably, from simple scheduled scripts to
   container-based and enterprise pipeline integrations.

**Data Integration** (:doc:`data_integration`)
   Connect OpenSTEF to your data sources — S3, Databricks, InfluxDB, PostgreSQL, or a custom backend —
   and understand the expected input formats.

**Migrating from V3 to V4** (:doc:`migration_v3_v4`)
   Breaking changes, updated APIs, and a step-by-step checklist for upgrading existing V3 codebases to
   the V4 architecture.
