User Guide
==========

This section covers practical implementation topics — how to integrate OpenSTEF into your systems,
deploy it in production, and apply it to real-world forecasting problems.

- **Use Cases** (:doc:`use_cases`)
   Explore concrete forecasting scenarios — congestion management, transport forecasts, and grid losses — with worked examples showing how to apply the library to each.

- **Deployment** (:doc:`deployment`)
   Production deployment patterns for running OpenSTEF at scale, from simple scheduled scripts to containerised pipelines and enterprise integrations.

- **Data Integration** (:doc:`data_integration`)
   Connect OpenSTEF to your data sources — S3, Databricks, InfluxDB, PostgreSQL, and custom backends — with patterns for reading and writing forecast data.

- **Migrating from V3 to V4** (:doc:`migration_v3_v4`)
   Breaking changes, updated APIs, and a step-by-step migration path for upgrading existing V3 codebases to the V4 architecture.
