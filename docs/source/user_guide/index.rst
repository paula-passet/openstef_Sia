User Guide
==========

This section covers practical implementation topics for working with OpenSTEF in real projects — from integrating your data sources to deploying forecasting pipelines in production.

**Use Cases** (:doc:`use_cases`)
   Explore concrete forecasting scenarios — congestion management, transport forecasts, grid losses, and district heating — with working code examples for each.

**Deployment** (:doc:`deployment`)
   Choose and implement a deployment pattern for your environment, from simple scheduled scripts to containerised pipelines and enterprise integrations.

**Data Integration** (:doc:`data_integration`)
   Connect OpenSTEF to your data infrastructure — S3, Databricks, InfluxDB, PostgreSQL, or a custom source — and understand the expected input formats.

**Migrating from V3 to V4** (:doc:`migration_v3_v4`)
   Understand the breaking changes introduced in V4, update your API calls, and adapt your project structure to the new modular architecture.
