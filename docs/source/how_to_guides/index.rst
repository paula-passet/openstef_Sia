OpenSTEF is a Python library for short-term energy forecasting that provides machine learning pipelines for training models and generating forecasts. The library includes various components for data validation, feature engineering, and machine learning operations. The library is designed around pipelines that offer functionality for training models, creating forecasts, and evaluating performance. Available pipelines include train_model, create_forecast, optimize_hyperparameters, create_component_forecast, create_basecase_forecast, and train_create_forecast_backtest. OpenSTEF 4.0 represents a major architectural refactor focused on improving modularity, type safety, extensibility, and performance. The release aims to decouple external dependencies, adopt a more modular design, and generalize domain-specific logic to support use cases beyond specific geographic regions.
