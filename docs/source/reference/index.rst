Reference
=========

This section provides detailed technical information about OpenSTEF's internal structure and development history. Use these pages when you need to understand how the library is organized or track changes across versions.

The reference documentation helps you navigate the codebase, understand design decisions, and stay informed about updates that may affect your forecasting workflows.

What's in this section
----------------------

**Architecture** - Visual diagrams and explanations of OpenSTEF's package structure, showing how core components, models, and evaluation tools work together.

**Changelog** - Complete version history with breaking changes, new features, and bug fixes to help you upgrade safely and understand what's new.
